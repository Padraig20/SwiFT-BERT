## 📌&nbsp;&nbsp;Introduction
This project is a continuing effort after [SwiFT](https://arxiv.org/abs/2307.05916), using SwiFT for movie-related emotion prediction via the HBN dataset. We use several heads to further proceess the output of SwiFT, including a linear embedding, an MLP, and LSTM and a BERT model.

> Effective usage of this repository requires learning a couple of technologies: [PyTorch](https://pytorch.org), [PyTorch Lightning](https://www.pytorchlightning.ai). Knowledge of some experiment logging frameworks like [Weights&Biases](https://wandb.com), [Neptune](https://neptune.ai) is also recommended.

## 1. Description
This repository implements a SwiFT framework for timestamp-specific prediction. 
- Our code offers the following things.
  - Trainer based on PyTorch Lightning for running the SwiFT integrated framework.
  - Data preprocessing/loading pipelines for 4D fMRI datasets.

## 3. Architecture

The input is a raw 4D fMRI image (h,w,d,t), and the output is a vector of emotions for each timeframe (t,e), where t is the number of timeframes and e is the number of emotions we want to predict per timeframe. This architecture illustrates how SwiFT, a transformer-based model, serves as an encoder for various classification heads, each designed to use the model's extracted embeddings for emotion decoding:

- **Linear Layer:** A straightforward classification head that applies a single fully connected layer to SwiFT's embeddings. This approach is computationally efficient and suitable for simpler tasks where linear separability of features suffices.
- **Deep MLP (Multi-Layer Perceptron):** A more sophisticated alternative to the linear layer, utilizing a 3-layer perceptron. This head is designed to learn complex, non-linear patterns in the embeddings, providing greater predictive capacity at the cost of additional computational complexity and parameters.
- **LSTM (Long Short-Term Memory):** By training an LSTM on the embeddings generated by SwiFT, this head captures temporal dependencies and contextual information within the data. The one-directional memory of the LSTM offers a lightweight approach to sequential modeling, effectively integrating temporal dynamics without requiring the bidirectional complexity of more advanced models.
- **BERT (Bidirectional Encoder Representations from Transformers):** This head leverages a (pre-trained) BERT model without its embedding layer, directly utilizing SwiFT's embeddings as input. By doing so, it combines SwiFT's spatial and temporal encoding capabilities with BERT's powerful self-attention mechanism and deep contextual understanding in a bidirectional manner. This enables the model to refine the extracted embeddings, capturing intricate relationships between features across all dimensions of the input data.

The design of this framework draws inspiration from Named Entity Recognition (NER) in Natural Language Processing (NLP), where each (sub-)word (token) is classified based on the context provided by surrounding tokens. Similarly, in this task, each fMRI image (representing a timepoint or token) is classified with respect to the surrounding timepoints, predicting an associated emotion. This parallel motivates the inclusion of models like LSTM and BERT, which are designed for capturing contextual relationships, and we expect that they will enhance performance.

To make use of the temporal context effectively, the embeddings from SwiFT need to be processed differently than in the original SwiFT architecture. Specifically, we flatten the spatial dimensions, including the channel dimension, while preserving the temporal sequence of timepoints. This transformation ensures that temporal information remains intact, enabling the LSTM or BERT to exploit their contextual understanding. The LSTM can capture sequential dependencies, while BERT's bidirectional attention mechanism can analyze temporal relationships in a holistic manner.

## 4. TODOs

- **Assess SwiFT-BERT Feasibility:** What concerns me is the use of a transformer (BERT) on top of another transformer (SwiFT). Given the limited data available, SwiFT’s embeddings might not provide sufficient information to effectively train the BERT model on top. We need to investigate whether SwiFT-BERT’s added complexity provides meaningful gains over SwiFT-LSTM. Currently, SwiFT-LSTM is expected to perform better due to its lighter architecture and ability to incorporate temporal dynamics efficiently.
- **Evaluate Temporal Patching Impact:** Analyze how temporal patching affects the size and quality of the embeddings. Determine whether this process obstructs or preserves the temporal information critical for downstream tasks.
- **Explore ICA-Extracted Features:** Investigate the potential of ICA-extracted features for improving prediction performance. These features might offer alternative insights, but using them would require a paradigm shift, as temporal information would no longer be available. What architecture would we use?
